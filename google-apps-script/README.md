# Google Apps Script для автоматизації таблиць Geneo (31 вкладка)

Цей скрипт (`GeneoAutoSync.gs`) призначений для встановлення у вашу **Google Таблицю** родоводу (де зберігаються таблиці `basic`, `names`, `families`, `familyChildren`, `birth`, `events` тощо).

---

## 🚀 Як підключити скрипт до Google Таблиці

1. Відкрийте вашу Google Таблицю родоводу в браузері.
2. У верхньому меню оберіть: **Розширення (Extensions)** ➔ **Apps Script**.
3. Видаліть наявний порожній шаблон (`myFunction`) та вставте вміст файлу `GeneoAutoSync.gs`.
4. Натисніть іконку **💾 Зберегти (Save project)** (Ctrl + S) та задайте назву проєкту (наприклад, `Geneo AutoSync`).
5. Перезавантажте вкладку з Google Таблицею.
6. У верхньому меню Google Таблиці з'явиться новий пункт: **🧬 Geneo**!

---

## 📌 Можливості меню «🧬 Geneo»

### 1. 🔄 Автооновлення зв'язків (Families & Children)
- **Проблема, яку вирішує:** вам більше не потрібно вручну створювати записи `FAM_0001` у вкладці `families` та зв'язувати `FC_0001` у вкладці `familyChildren`.
- **Як користуватися:**
  - Просто внесіть нового родича у вкладку `basic` (та `names`), вказавши в полях `father_id` або `mother_id` ID батьків.
  - Натисніть **🧬 Geneo ➔ 🔄 Автооновлення зв'язків**.
  - Скрипт автоматично перевірить наявність подружжя, створить сімейний запис у `families` та прив'яже дитину у `familyChildren`.

### 2. 🔍 Повний аудит дерева (Дублікати та помилки)
- Знаходить потенційні дублікати (однакові ПІБ та близькі роки народження).
- Перевіряє аномалії віку батьків:
  - Вік матері при пологах < 13 або > 53 років;
  - Вік батька при народженні дитини < 13 або > 85 років;
  - Народження дитини після смерті матері або через > 1 рік після смерті батька.
- Перевіряє хронологічні помилки:
  - Смерть раніше за народження;
  - Тривалість життя > 115 років;
  - Статус «живий» при віці понад 120 років.
- Автоматично створює вкладку **`_Audit_Geneo`** з кольоровим підсвічуванням та рекомендаціями.

### 3. 🆔 Автогенерація відсутніх ID
- Якщо ви швидко внесли нових родичів і залишили першу колонку `id` порожньою, цей пункт автоматично присвоїть послідовні ID (`I0001`, `F0001`, `FC0001`, `EV0001`).
